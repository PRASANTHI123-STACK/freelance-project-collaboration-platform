# Git Collaboration Workflow

## Branching

The project uses `main` as the stable branch.

Feature development is performed using separate feature branches.

## Development Workflow

1. Create a feature branch.
2. Implement the assigned feature.
3. Commit the changes with a meaningful message.
4. Push the feature branch to GitHub.
5. Create a Pull Request.
6. Request a teammate review.
7. Address review comments if required.
8. Get approval.
9. Merge the Pull Request into `main`.

## Team Collaboration

The project uses GitHub Pull Requests for code review and collaborative development.
